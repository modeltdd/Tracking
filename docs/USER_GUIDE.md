# คู่มือการใช้งาน — ระบบติดตามสถานะผลงานวิชาการ สำนักงานเขตสุขภาพที่ 11

ระบบมีผู้ใช้งาน 3 กลุ่ม เข้าใช้งานผ่านลิงก์ Web App เดียวกัน แต่ระบบจะพาไปหน้าที่ต่างกันตามสิทธิ์:

| กลุ่มผู้ใช้ | วิธีเข้าถึง | เอกสารส่วนนี้ |
|---|---|---|
| ประชาชน / เจ้าของผลงาน | เปิดลิงก์ Web App โดยไม่ต้อง Login | [ส่วนที่ 1](#1-ประชาชน--เจ้าของผลงาน-ไม่ต้อง-login) |
| เจ้าหน้าที่ (ทุกหน่วยงาน) | Login ด้วย Google Account ที่แอดมินเพิ่มไว้ในระบบ | [ส่วนที่ 2](#2-เจ้าหน้าที่) |
| ผู้ดูแลระบบ (Admin) | Login เหมือนเจ้าหน้าที่ แต่มี role = Admin | [ส่วนที่ 3](#3-ผู้ดูแลระบบ-admin) |

## 1. ประชาชน / เจ้าของผลงาน (ไม่ต้อง Login)

เปิดลิงก์ Web App จากเบราว์เซอร์มือถือหรือคอมพิวเตอร์ (ไม่ต้อง Login Google) จะเข้าหน้า **"ตรวจสอบสถานะ"** ทันที

### วิธีตรวจสอบสถานะ

1. กรอก **เลขติดตามเอกสาร** (ได้รับตอนเจ้าหน้าที่ลงทะเบียนรับเรื่อง อยู่ใต้ QR บนใบนัด/สำเนาเอกสาร)
2. กรอก **เลขบัตรประชาชน 4 ตัวท้าย**
3. กด "ตรวจสอบสถานะ"

ระบบจะแสดง:
- สถานะปัจจุบัน (เช่น รับเรื่องแล้ว / กำลังตรวจสอบ / อยู่ระหว่างพิจารณา / ส่งกลับแก้ไข / ประกาศผลแล้ว / เสร็จสิ้น)
- ขั้นตอนถัดไปที่ต้องรอ
- ถ้าอยู่ในสถานะ **"ส่งกลับแก้ไข"** — ระบบจะแสดงกล่องรายละเอียดสิ่งที่ต้องแก้ และกำหนดส่งฉบับแก้ไขกลับ

### ข้อควรรู้

- ค้นหาผิดติดกันหลายครั้งเกินจำนวนที่กำหนด (ค่าเริ่มต้น 5 ครั้ง) ระบบจะล็อกชั่วคราว (ค่าเริ่มต้น 10 นาที) กันสุ่มเดาเลขบัตรประชาชน — รอเวลาที่แจ้งแล้วลองใหม่
- หน้านี้ไม่แสดงข้อมูลส่วนบุคคลอื่นนอกจากของเจ้าของเลขติดตามนั้นเอง

## 2. เจ้าหน้าที่

### 2.1 เข้าใช้งาน

เปิดลิงก์ Web App เดียวกัน แล้ว **Login ด้วย Google Account** — ต้องเป็นอีเมลที่ผู้ดูแลระบบเพิ่มไว้ในระบบแล้วและสถานะ "ใช้งาน" (active) เท่านั้น ถ้ายังไม่มีสิทธิ์ ระบบจะขึ้นหน้า "ไม่มีสิทธิ์เข้าใช้งาน" — แจ้งผู้ดูแลระบบให้เพิ่มชื่อ

เข้าแล้วจะเห็นเมนูล่างจอ (bottom-nav) 3–4 ปุ่ม: **หน้าแรก, สแกน QR, ค้นหา** (และ **ผู้ดูแล** ถ้าเป็น Admin)

### 2.2 หน้าแรก (Dashboard)

สรุปงานของ **หน่วยงานตัวเอง** เป็น 6 กลุ่ม:

| กลุ่ม | ความหมาย |
|---|---|
| งานรอรับ | ถูกส่งต่อมาแล้ว แต่ยังไม่มีใครสแกนรับที่หน่วยงานนี้ |
| กำลังดำเนินการ | หน่วยงานนี้ถือเอกสารอยู่ตอนนี้ |
| ส่งต่อแล้ว รอปลายทางรับ | หน่วยงานนี้ส่งต่อไปแล้ว รอหน่วยงานถัดไปสแกนรับ |
| ใกล้ครบกำหนด | อยู่ในขั้นตอนนี้เกิน 80% ของเวลามาตรฐานแล้ว |
| เกินกำหนด | อยู่ในขั้นตอนนี้เกินเวลามาตรฐานแล้ว |
| ส่งกลับแก้ไข | รอเจ้าของผลงานส่งฉบับแก้ไขกลับมา |

กดปุ่ม **"+"** มุมล่างขวา เพื่อลงทะเบียนรับเอกสารใหม่

### 2.3 ลงทะเบียนรับเอกสารใหม่

กรอกแบบฟอร์ม: คำนำหน้า/ชื่อ/นามสกุล, ตำแหน่ง, ระดับปัจจุบัน/ระดับที่ขอ, ประเภทผลงาน, ชื่อผลงาน, หน่วยงานต้นสังกัด, เลขบัตรประชาชน 13 หลัก, เบอร์โทร/อีเมล (ถ้ามี)

- แนบ **ภาพหน้าปกผลงาน** ได้ (ไม่บังคับ) — เก็บไว้เป็นไฟล์แนบใน Google Drive เท่านั้น ไม่มีการอ่านข้อมูลอัตโนมัติจากภาพ ต้องกรอกฟอร์มเองทุกช่อง
- กด **"บันทึกและออกเลขติดตาม"** ระบบจะออก **เลขติดตาม + QR Code** ให้ทันที
- **พิมพ์/แปะ QR นี้ไว้บนเอกสาร** ใช้สแกนรับงานที่หน่วยงานถัดไป และเจ้าของผลงานใช้เลขติดตามนี้ตรวจสอบสถานะเองได้ (ส่วนที่ 1)

### 2.4 สแกน QR รับงาน / ทำ Action

จากเมนู "สแกน QR": เปิดกล้องมือถือสแกน QR บนเอกสาร (ระบบเปิดหน้ารับงานอัตโนมัติ) หรือกรอกรหัส QR 8 ตัวเองได้ถ้ากล้องอ่านไม่ออก

ปุ่ม Action ที่เห็นจะเปลี่ยนไปตามสถานะงานและสิทธิ์ของผู้ใช้ (ระบบตรวจสิทธิ์ฝั่ง server ทุกครั้ง กดได้เฉพาะปุ่มที่ระบบอนุญาตจริง):

| Action | ความหมาย | ใครกดได้ |
|---|---|---|
| รับเอกสารและเริ่มดำเนินการ | รับมอบเอกสารที่ถูกส่งต่อมา เข้าสู่ขั้นตอนของหน่วยงานตน | หน่วยงานปลายทางที่รอรับ |
| ผ่านและส่งต่อขั้นตอนถัดไป | ผ่านขั้นตอนนี้ ส่งเอกสารต่อไปหน่วยงาน/ขั้นตอนถัดไป | เจ้าของงานปัจจุบัน (หน่วยงานที่ถือเอกสารอยู่) |
| ขอข้อมูลเพิ่มเติม | บันทึกว่าต้องขอข้อมูล/เอกสารเพิ่มจากเจ้าของผลงาน | เจ้าของงานปัจจุบัน |
| ส่งกลับให้เจ้าของผลงานแก้ไข | ส่งกลับพร้อมกำหนดวันส่งคืน แสดงในหน้าตรวจสอบสถานะสาธารณะ | เจ้าของงานปัจจุบัน |
| ไม่ผ่านการพิจารณา | จบกระบวนการแบบไม่ผ่าน | เจ้าของงานปัจจุบัน |
| ยุติกระบวนการ | ยกเลิก/ยุติกลางคัน (เช่น ผู้ยื่นขอถอนเรื่อง) | เจ้าของงานปัจจุบัน |
| ปิดงาน (ข้ามขั้นตอนที่เหลือ) | ปิดงานทันทีโดยไม่ต้องผ่านขั้นตอนที่เหลือ | **Admin เท่านั้น** |
| เปลี่ยนผู้รับผิดชอบ/ย้ายสถานี | ย้ายเจ้าของงานไปหน่วยงานอื่น หรือย้ายกลับไปสถานีก่อนหน้านอกลำดับปกติ (เช่น ดันกลับเข้ารอบพิจารณาใหม่หลังแก้ไขงานเสร็จ — ดูหมายเหตุด้านล่าง) | **Admin เท่านั้น** |

หมายเหตุ: "เจ้าของงานปัจจุบัน" คือหน่วยงานที่ระบบบันทึกว่าถือเอกสารอยู่จริง (ไม่ใช่ระหว่างส่ง/รอส่งมอบ) — ถ้าเอกสารกำลังลอยอยู่ระหว่างส่งต่อ (ยังไม่มีใครสแกนรับ) หน่วยงานต้นทางจะกดปุ่มดำเนินการต่อไม่ได้แล้ว ต้องรอปลายทางสแกนรับก่อน

**หมายเหตุเรื่องรอบพิจารณาที่ 2 (กรณี "แก้ไข"):** ระบบไม่มีสถานีแยกสำหรับรอบ 2 — ใช้สถานี "เลขาส่งเอกสารให้กรรมการ → ประธานนัดประชุม → กรรมการประชุมพิจารณา → เลขาแจ้งผล" ชุดเดิมซ้ำ เมื่อได้รับเอกสารที่แก้ไขแล้วกลับมา **Admin ต้องกดปุ่ม "เปลี่ยนผู้รับผิดชอบ/ย้ายสถานี" แล้วเลือกช่อง "ย้ายไปสถานี" กลับไปที่ "เลขาส่งเอกสารให้กรรมการ" ด้วยตนเอง** (ปุ่ม "ผ่านและส่งต่อ" ธรรมดาทำแบบนี้ไม่ได้ เพราะแต่ละสถานีส่งต่อได้ปลายทางเดียวคงที่)

### 2.5 ค้นหา

ค้นหางานของหน่วยงานตัวเองด้วยชื่อ/เลขติดตาม/เลขบัตรประชาชน เลือกรายการเพื่อดู **รายละเอียด + Timeline** ประวัติทุกขั้นตอนที่ผ่านมา

## 3. ผู้ดูแลระบบ (Admin)

Login เหมือนเจ้าหน้าที่ทั่วไป แต่บัญชีมี role = **Admin** จะเห็นเมนูเพิ่ม **"ผู้ดูแล"** ที่ bottom-nav และมีสิทธิ์กด "ปิดงาน"/"เปลี่ยนผู้รับผิดชอบ" ในหน้าสแกน QR ได้ (ส่วนที่ 2.4)

หน้า "ผู้ดูแล" แบ่งเป็น 5 แท็บ:

### 3.1 แดชบอร์ดผู้บริหาร (Overview)

สรุปภาพรวม **ทุกหน่วยงาน** พร้อมกัน (ต่างจาก Dashboard ของเจ้าหน้าที่ที่เห็นเฉพาะหน่วยงานตัวเอง) — จำนวนงานแยกตามสถานะ และตารางแยกตามหน่วยงาน (งานรอรับ/กำลังดำเนินการ/ใกล้ครบกำหนด/เกินกำหนด)

### 3.2 จัดการ Workflow

จัดการลำดับขั้นตอน/สถานี (WorkStations) — เพิ่ม/แก้ไขสถานี, กำหนดหน่วยงานเจ้าของแต่ละสถานี, สถานีถัดไป, ระยะเวลามาตรฐาน (วัน), สถานะที่แสดงต่อสาธารณะ

**ข้อควรระวัง:** `station_key` (รหัสสถานี) แก้ไขไม่ได้หลังสร้าง — ถ้าตั้งผิดต้องสร้างสถานีใหม่แทน การแก้ workflow มีผลกับงานที่กำลังเดินอยู่ทันที ควรแก้นอกเวลาทำการหรือแจ้งเจ้าหน้าที่ก่อน

### 3.3 จัดการผู้ใช้งาน

เพิ่ม/แก้ไข/ปิดใช้งานบัญชีเจ้าหน้าที่ — กำหนดอีเมล, ชื่อแสดงผล, บทบาท (role), หน่วยงาน, สถานะใช้งาน

บทบาทที่เลือกได้: `Admin`, `เจ้าหน้าที่รับเอกสาร`, `เจ้าหน้าที่ผู้รับผิดชอบ`, `ผู้ดูข้อมูลอย่างเดียว`

> **หมายเหตุสำคัญ:** ปัจจุบันสิทธิ์กดปุ่ม Action จริงในระบบอิงจาก **หน่วยงาน (organization)** ของผู้ใช้เป็นหลัก ไม่ได้อิงจากชื่อบทบาทเหล่านี้ (ยกเว้น `Admin` ที่ปลดล็อกปุ่ม "ปิดงาน"/"เปลี่ยนผู้รับผิดชอบ" และเข้าหน้าผู้ดูแลได้) ดังนั้นบทบาท "ผู้ดูข้อมูลอย่างเดียว" ยังไม่ได้ทำให้บัญชีนั้นกดปุ่ม Action ไม่ได้จริง — ใช้เป็นป้ายกำกับ/ข้อมูลอ้างอิงเท่านั้นในตอนนี้ ถ้าต้องการบังคับสิทธิ์แบบอ่านอย่างเดียวจริง ต้องแจ้งพัฒนาเพิ่ม

ระบบกันแอดมินถอด role ตัวเองออกจาก Admin หรือปิดใช้งานบัญชีตัวเอง (self-lockout guard) เพื่อไม่ให้ล็อกตัวเองออกจากระบบโดยไม่ตั้งใจ

### 3.4 Audit Log

ดูประวัติการเปลี่ยนแปลงข้อมูล (ใครแก้อะไร เมื่อไหร่ ค่าเดิม→ค่าใหม่) — แสดง 200 รายการล่าสุด

### 3.5 รายงาน CSV

ดาวน์โหลดข้อมูลงานทั้งหมด หรือ Audit Log เป็นไฟล์ CSV (มี BOM ในตัว เปิดด้วย Excel แล้วภาษาไทยไม่เพี้ยน)

## ภาคผนวก: สร้างข้อมูลตัวอย่างเพื่อทดสอบ

สำหรับผู้ดูแลระบบที่ต้องการข้อมูลตัวอย่างไว้ทดสอบระบบ (ไม่ใช่หน้าเว็บ ต้องรันจาก Apps Script Editor):

- `seedSampleData()` — สร้างงานตัวอย่าง 6+1 เคส ครอบคลุมทุกกลุ่มใน Dashboard
- `clearSampleData()` — ลบข้อมูลตัวอย่างทั้งหมดออก (ลบเฉพาะแถวที่สร้างจากฟังก์ชันนี้)
- `migrateWorkStationsToRealProcess()` — ล้างสถานี Workflow เดิมทั้งหมดแล้วตั้งใหม่ตามกระบวนการจริง 7 ขั้น (`WORKSTATIONS_SEED` ปัจจุบัน) รันครั้งเดียวตอนย้ายระบบที่มีสถานีชุดเดิมอยู่แล้ว — **ให้เคลียร์ข้อมูลทดสอบ (`clearSampleData()`) หรือย้ายงานจริงก่อนรันเสมอ** เพราะงานที่อ้าง station_key เดิมจะหาสถานีไม่เจอหลังรัน
